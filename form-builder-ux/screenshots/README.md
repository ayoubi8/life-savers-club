## Capture tips

- Use a realistic form with at least five question types.
- Include one required question, one choice question and one file question.
- Capture both FR and EN if the redesign must handle long labels.
- Use a phone width around 390 px and a desktop width around 1440 px.
- Avoid showing real respondent personal data; use fake names and emails.
